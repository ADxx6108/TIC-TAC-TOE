# Tic-Tac-Toe

This is a small two-player Tic-Tac-Toe game made with Python. It runs in the terminal and does not need any extra packages.

## What it can do
- Play with two people
- Show a 3 x 3 board
- Use X and O turns
- Check invalid input
- Check for a winner
- Detect a draw
- Start another game after finishing

## Requirements
Python 3.x is enough. There are no external libraries.

## Run the game
Open the project folder in VS Code, PyCharm, or a terminal and run:

```text
python main.py
```

## Run the tests

```text
python test_game.py
```

If the tests pass, the program prints:

```text
All tests passed.
```

## Files

- `main.py` starts the program.
- `game.py` controls the game loop.
- `board.py` handles the board.
- `players.py` gets and checks player moves.
- `rules.py` contains the winning rules.
- `test_game.py` contains a few basic tests.
- `statement.md` describes the project.

## Python concepts used
The project uses classes, functions, lists, loops, conditions, input validation and modules.
