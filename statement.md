# Problem Statement

## Problem
Make a simple console-based Tic-Tac-Toe game in Python for two players. The project should use basic Python concepts such as classes, functions, loops, conditions and input handling.

## Scope
The game is played by two people on a 3 x 3 board. Players take turns choosing a position from 1 to 9. The program checks for a win or a draw after every move and gives the option to start another game.

## Users
- Students learning Python
- Beginners practising basic programming
- Anyone who wants to play a simple two-player console game

## Main Features
1. Show the game board.
2. Take moves from two players.
3. Check whether the entered move is valid.
4. Check for a winning combination.
5. Detect a draw.
6. Ask whether another game should be played.
